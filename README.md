This is a Placement Portal App created using Python flask, vue.js, Sqlite and HTML/CSS. 

To run the project, open the root directory (folder containing backend and frontend folder) in command prompt and run "npm install -g @vue/cli". 

Once installed open frontend ("cd frontend" in command prompt) and then run "npm install".

Once installed run "npm run serve" in the same directory.

Then open the createdatabase.py file and run it.

Then run the app.py file.

Now open the link from the command promt received after running "npm run serve".

And you are good to go....
